# Agent guidance

- Work in place. Today `bin/secret` is the Bash CLI, `hooks/guard-secrets` is the Claude Code and Codex guard, and `cmd/secret` is the Go CLI under staged parity review. `skills/` carries agent guidance, `codex/` holds manual hook setup, `examples/` holds ripgrep config, `tests/` holds synthetic shell suites, and `.claude-plugin/`, `.codex-plugin/`, `.agents/plugins/` hold plugin manifests. Follow [ROADMAP.md](ROADMAP.md), the [Go rewrite plan](docs/design/go-rewrite.md) and the [M3 plan](docs/design/m3-plan.md). Go code lives in `internal/cli`, `internal/hook`, `internal/store`, `internal/backend`, `internal/transport`, `internal/feature` (operator and names-only interfaces), `internal/secure` (byte ownership and fixed errors), and synthetic `testdata/`.
- Run shell tests with `bash tests/test-secret.sh` (CLI, Perl, Python 3, ripgrep), `bash tests/test-backends.sh` (stub), `bash tests/test-guard.sh` (jq), `bash tests/test-codex.sh` (Codex), `bash tests/test-libsecret.sh` (isolated Secret Service), and `bash tests/test-keychain.sh` (disposable macOS Keychain). Use the required-provider CI modes `SECRET_REQUIRE_LIBSECRET=1` and `SECRET_REQUIRE_KEYCHAIN=1` only in isolated provider environments. Run `shellcheck bin/secret hooks/guard-secrets tests/*.sh`; where available, run the shell suites with stock macOS `/bin/bash` 3.2 as well. For Go changes, run `gofmt -l .`, `go build ./...`, `go vet ./...`, `go test -count=1 ./...`, and `go test -race ./internal/...`, plus focused tests and applicable shell suites. Cross-vet with `GOOS=windows go vet ./...` and `GOOS=darwin go vet ./...` does not replace native CI.
- Run M3 synthetic tests with `go test ./internal/cli ./internal/feature ./internal/secure ./internal/backend ./internal/store`. Build a default Go CLI and run `python3 -I tests/test-operator.py ABSOLUTE_BINARY` for Unix PTY confirmation, hidden input, lifecycle, JSON, MCP and template cleanup; it skips cleanly without PTYs. CI fuzzes `FuzzMetadataSelection`, `FuzzPrivateImporterJSON` and `FuzzMCPProtocol` in `internal/feature` with bounded budgets. `TestOperatorLibsecretIntegration` and `TestOperatorKeychainIntegration` use the existing required-provider environment gates on their isolated Linux/macOS runners only; never enable them locally. Keep operator values out of argv, JSON and audit. Do not weaken M2 denial to enable new commands through agents.
- Treat the GitHub Actions matrix as the gate. Open a PR or push a branch to trigger CI. `.github/workflows/ci.yml` runs Ubuntu/macOS shell suites, isolated providers and macOS Bash 3.2, plus Go checks on Ubuntu, macOS and Windows. The Go binary has not replaced the Bash CLI. Require green applicable runner jobs before calling a milestone complete.
- Keep `testdata/inventory/` exact: review regenerated keys and expectations for every intentional shell test change. The four CLI/provider shell suites accept `SECRET_CLI=/absolute/path/to/secret` to test an alternate executable; without it they use `bin/secret`. Use `bash tests/go-cli.sh SUITE /absolute/path/to/go-binary` to enforce the exact case failures in `testdata/inventory/go-expected-divergence.tsv`. Build the stub-only binary with `go build -tags secretstub` for the backends suite; never enable it in production. Run libsecret and keychain only on their isolated CI runners.
- The guard suites accept `SECRET_GUARD='/absolute/path/to/secret hook claude'` (or `hook codex`). The default Go build analyzes shell calls with the bounded AST policy, 64 KiB envelopes and 40 KiB fragments; Codex patches have a 40 KiB header check that denies malformed framing. Explicit Bash workdir anchors paths at the envelope cwd; Codex still omits per-command workdir. There is no `hooktrial` split. The installed Bash hook and plugin manifests remain unchanged. Do not claim installed protection or host fail-closed behavior from synthetic Go tests.
- Use `bash tests/go-hook.sh guard|codex ABSOLUTE_BINARY claude|codex` for exact case outcomes. Regenerate `testdata/inventory/go-hook-divergence.tsv` with `python3 -I tests/gen-go-hook-divergence.py ABSOLUTE_BINARY`; it permits only reviewed find-shim and tightening categories and also measures the permanent audit envelopes. Every row must have a named entry in `docs/design/hook-tightening.md`. `tests/trial-go-hook.py` builds a disposable default binary for grouped counts and process-launch-inclusive p99.
- Regenerate denied-command metadata fixtures with `python3 -I tests/gen-hook-variants.py`. The Go corpus test checks semantics-preserving literal quoting, escaping, brace and wrapper variants, including audit reproducers. Seven Bash-only external dependency fault cases stay recorded but use Go scanner fault-injection tests rather than command-text variants. Never remove a real failing variant or change an expectation to hide an allow.
- Keep retained shell code Bash 3.2-compatible: avoid associative arrays, `mapfile`, `readarray`, `${var,,}`, and Bash 4-only features. Do not source credential stores. Preserve quoted expansions and private atomic writes.
- Keep secret values as `[]byte` in Go, never in errors, logs or argv. Put table-driven synthetic tests in the same commit as each behavior change; do not weaken a guard expectation without a classified reason and reviewed tightening/differential record. Regenerate stash byte fixtures with `bash testdata/store/gen.sh OUTPUT_DIR`, compare against `testdata/store/golden/`; regenerate CLI cases with `bash testdata/cli/gen.sh OUTPUT_DIR` and compare against `testdata/cli/golden/`, and keep the provider directory stub in test files only. A killed Go writer leaves a tokened `.write-lock` for manual verification and removal, never automatic stealing. The next lock owner cleans marked private scratch; do not use a real store for tests.
- Never read, inspect or use real credentials or stores. Use synthetic fixtures and disposable provider targets only. Do not touch a user's actual Keychain or keyring, or install hooks on the host.
- Keep commits conventional and lowercase (`type(scope): summary`), signed, and free of co-author trailers. Write no em or en dashes and no emojis. Update [ROADMAP.md](ROADMAP.md), [CHANGELOG.md](CHANGELOG.md) and relevant documentation in the same PR as changed behavior. Do not commit or push unless asked.

The security model is accident prevention, not a sandbox: the CLI supplies selected values to a child and redacts literal output; the hook denies known secret-reading operations but cannot contain a determined agent, transformed values, unobserved tools or arbitrary child behavior. Do not claim fail-closed host protection without host evidence. Report potential value leaks privately with synthetic reproduction only; see [SECURITY.md](SECURITY.md).
