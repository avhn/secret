Let coding agents use your credentials without reading them.

A local credential CLI, a names-only MCP server, and a guard hook for coding agents.

Agents see key names, labels and paths, never values through the names-only interface. The CLI passes selected values directly to programs; the guard denies known store-reading operations.

What you get

The secret CLI
Stash values with a hidden prompt, list masked names, and run a program with only the selected keys in its environment. secret run replaces every loaded value with <redacted> on the child's stdout and stderr.
A names-only MCP server
Opt-in local stdio with exact, human-approved --store references. Four read-only tools, list, show, diff and health, never return values, value hashes or lengths. Tool reference.
A guard hook
The optional Claude Code and Codex plugins install the Bash guard and agent skill. The guard denies common accidents such as reading store files, dumping the environment and credential printers like gh auth token.

Accident prevention, not a sandbox. Read the security model and limits.

How it works

  1. The agent asks for a credential by key name, not its value.
  2. secret hands the selected value directly to the program's environment.
  3. secret run redacts loaded literal values from stdout and stderr.

Install

Install or update the secret CLI to the latest release. Linux/macOS:

curl -fsSL https://raw.githubusercontent.com/avhn/secret/v0.5.0/install.sh | sh

Windows PowerShell:

irm https://raw.githubusercontent.com/avhn/secret/v0.5.0/install.ps1 | iex

No GitHub account or gh is needed; rerunning updates the installation. Both installers print the concrete executable path. Neither reads stores, registers MCP, installs hooks or edits clients. See setup for pins, rollback, paths and client registration.

Or let your agent set it up

Follow https://github.com/avhn/secret/blob/v0.5.0/docs/setup.md to install and register secret MCP; ask me for the exact intended store references, never discover or read stores, handle values, run operator consent commands, or bypass a guard.

The agent asks you which exact stores may expose metadata to its client. You enter values yourself; the agent never sees them.

First commands

In your own terminal, stash a value with a hidden prompt. Agents can use show and run, but must never enter or retrieve values. These are illustrative paths:

secret stash ~/.secrets.env API_TOKEN
secret show ~/.secrets.env
secret run -f ~/.secrets.env --key API_TOKEN -- ./deploy.sh
  • stash reads the value from a hidden prompt and writes the store atomically.
  • show prints key names with masked lengths, such as API_TOKEN=<40 bytes>.
  • run exports only the selected keys to the child and redacts every loaded value from its output.
